# DriveX

Premium Vehicle Rental Platform

## Overview
DriveX is a startup-quality luxury vehicle rental platform built with React, Vite, Tailwind, Node.js, Express, MongoDB Atlas, Cloudinary, and Razorpay.

## Architecture
The project is split into three main applications:
- `frontend/` for the customer-facing experience
- `backend/` for the REST API, business logic, authentication, and payment processing
- `admin/` for the secure admin panel application and admin-specific UI workflows
